# playlist-maker-android-TreninDenis

**Playlist Maker - это музыкальное приложение для Android, позволяющее пользователям:**

Искать треки через iTunes API  
Добавлять треки в избранное  
Создавать и управлять плейлистами  
Добавлять обложки к плейлистам  
Просматривать детальную информацию о треках  

**Основной стек технологий:**

Kotlin  
Jetpack Compose (UI)  
Room (база данных)  
Retrofit (сетевые запросы)

**Версии инструментов**  

Android Studio Narwhal 3 Feature Drop | 2025.1.3  
Gradle 8.13  
Kotlin 2.0.21  

Android SDK  
Минимальная версия SDK: 29  
Целевая версия SDK: 36  
Версия компиляции SDK: 36  

**Шаги запуска**

1. Клонирование проекта
2. Открытие проекта в Android Studio
3. Настройка эмулятора
4. Сборка и запуск приложения
